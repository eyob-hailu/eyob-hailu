        <img src="https://img.shields.io/badge/License-MIT-blue.svg" />
      </h3>
      <p>
        <strong>The Problem It Solves:</strong> In Node.js, developers needing enterprise security face a tough choice: adopt the heavy NestJS monolith, deal with dated Passport.js callback hell, or manually drill <code>req.user</code> down through every service, repository, and controller.
      </p>
      <p>
        <strong>The Solution:</strong> <code>express-spring-security</code> brings the battle-tested design patterns of <strong>Spring Security 6</strong> directly to Express 5 & TypeScript with zero framework lock-in. It provides ambient context powered by native <code>AsyncLocalStorage</code> (eliminating <code>req.user</code> parameter-drilling), fluent declarative <code>SecurityFilterChain</code>, and universal <code>@PreAuthorize</code> method security decorators.
      </p>
